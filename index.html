How This Benchmark Data Is Collected & Verified

Dual-Layer Pipeline

Raw model cards on Hugging Face frequently omit scores (e.g. models not reporting suites where they trail, or linking out to external PDFs). To guarantee total coverage and comparability without bias or missing fields, this matrix uses a two-layer verification pipeline:

1. Peer-Reviewed Baselines

Scores extracted directly from official peer-reviewed publications, technical reports (arXiv), and standardized evaluator leaderboards (LiveCodeBench, SWE-bench Verified).

2. Automated 24h Sync

GitHub Actions runs daily to check official Hugging Face repositories. When model teams update benchmarks or issue revisions, scores automatically refresh and overlay.

3. Harness Normalization

Values flagged with ~ denote harness-adjusted or multi-run estimates where evaluation scaffolds (Claude Code, OpenHands, Terminus-2) differ slightly.
